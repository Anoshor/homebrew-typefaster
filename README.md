# homebrew-typefaster

Homebrew tap for [TYPEFASTER](https://github.com/Anoshor/typefaster-cli) — a
terminal-first typing game with ghosts and online multiplayer.

```bash
brew install Anoshor/typefaster/typefaster
typefaster            # play offline instantly
```

Online: `typefaster register <name>` (or `--github` / `--google`), then
`typefaster lobby create` / `typefaster lobby join <code>`.
